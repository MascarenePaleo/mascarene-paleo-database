# Database Methodology

## Objective

The Mascarene Paleo Database aims to compile a transparent and traceable record of palaeontological and subfossil material from the Mascarene Islands.

## Record acquisition

Potential records may be identified through:

- museum catalogues;
- museum-provided spreadsheets;
- Google Scholar;
- Web of Science;
- Scopus;
- Crossref;
- Biodiversity Heritage Library;
- Internet Archive;
- institutional repositories;
- monographs;
- historical literature;
- specimen photographs;
- 3D repositories;
- correspondence with collection staff and researchers.

## Candidate records

Newly discovered records should initially be treated as candidates when identification, provenance, repository, or duplication has not been checked.

## Verification

Where possible, verify a record against at least one primary source such as:

- the holding institution's catalogue;
- a specimen label or collection database;
- a taxonomic publication;
- a museum-provided inventory;
- a directly traceable historical catalogue.

## Duplicate handling

Do not delete apparently duplicated records until it is clear whether they represent:

- duplicate database entries;
- separate elements with one catalogue number;
- separate catalogue numbers from one individual;
- historical renumbering;
- casts or replicas;
- transferred specimens.

## Taxonomic changes

Historical identifications should be preserved in a dedicated field. Updated identifications should not erase the taxonomic history of a specimen.

## Uncertainty

Uncertain data should be explicitly marked. Do not convert uncertain historical information into precise modern values without evidence.

## Versioning

GitHub should contain the active database. Formal milestone versions can be archived through Zenodo.
