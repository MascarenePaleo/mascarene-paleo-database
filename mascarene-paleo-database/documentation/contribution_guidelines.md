# Contribution Guidelines

Mascarene Paleo welcomes corrections, new records, references, and verified additions.

## Preferred contribution

For each proposed record or correction, provide:

1. the affected record or proposed new record;
2. the source;
3. a stable URL, DOI, catalogue reference, or scan reference where possible;
4. a short explanation of the proposed change;
5. any uncertainty associated with the information.

## GitHub workflow

Contributors may use:

- GitHub Issues for corrections, questions, and candidate records;
- Pull Requests for structured data additions;
- direct contact with the project for larger datasets or museum inventories.

## Evidence standard

Claims should be traceable. Unsupported corrections may be retained as unresolved questions until they can be verified.

## Attribution

Substantial contributions should be acknowledged appropriately. Authorship on later publications should be based on scholarly contribution rather than database submission alone.
