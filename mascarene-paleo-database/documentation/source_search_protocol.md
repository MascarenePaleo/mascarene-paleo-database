# Source Search Protocol

Use this checklist when systematically expanding the database.

## Museum catalogues

Search by:

- accepted scientific names;
- historical synonyms;
- collector names;
- locality names;
- island names;
- historical collection names;
- known expedition names.

Record the search date and source in `sources/source_register.csv`.

## Literature databases

Recommended resources include:

- Google Scholar
- Web of Science
- Scopus
- Crossref
- Biodiversity Heritage Library
- Internet Archive
- institutional repositories
- relevant monographs and historical literature

## Search terms

Combine island/locality terms with taxonomic and collection terms, for example:

- Mauritius fossil
- Mauritius subfossil
- Rodrigues subfossil
- Réunion fossil
- Mascarene fossil vertebrate
- Mare aux Songes
- Thirioux Mauritius
- dodo specimen museum
- solitaire specimen museum
- Cylindraspis museum specimen

Expand searches using historical spellings and synonyms.

## Candidate workflow

1. Find potential record.
2. Assign an internal candidate/specimen ID.
3. Record the source immediately.
4. Check whether the record already exists.
5. Verify repository and catalogue number.
6. Verify taxonomic identification.
7. Verify locality/provenance where possible.
8. Mark uncertainty.
9. Add unresolved problems to `unresolved_questions.csv`.
10. Record the addition in the weekly changelog.
